Fable 5.1 は Fable 5 と何が違うのか

Fable 5.1 と Mythos 5.1マイソス は中身は同じモデルで、安全装置の強さだけが違います。Fable 5.1 が一般提供、Mythos 5.1 は審査を通った組織だけ（現状は米国の一部）。一般ユーザーが触るのは Fable 5.1 の方です ✅

投資会社ミレニアム（Millennium）のテストで、100万回に1回だけ落ちるバグの原因を Fable 5.1 が初めて特定。チームの誰も、Fable 5 を含むどのモデルも、4〜5年 説明できなかったものです 🔶（利用企業の証言）

⚠️ 向かない場面・注意（公式明記）

  • 承認の仕組みや自動モードの判定を、まだときどきすり抜けることがある
  • とても長い作業・複数AI同時実行は、行動の自動チェックが行き届きにくい
  • Claude Code では既定の「考える強さ」が最大（High）。応答は少し遅く、トークン消費は増える

「25%安くなる」ってどういうことか

値段の表示は据え置き（入力 $10 / 出力 $50）。安くなる理由はキャッシュ読み取り（一度処理した文脈をもう一度読むぶん）が 100万トークンあたり $1.00 → $0.25（−75%）になったこと ✅

Fable 5（これまで）
100
Fable 5.1（ふつうの使い方）
75（約25%減）
Fable 5.1（重い・道具を多く使う）
55（約45%減）

2026年8月の実使用4週間ぶんで測った内訳（Anthropic）

全員が安くなるわけではない／何をすると効くか
  • 安くなる人：使った量ぶん課金される人（API を直接／Codex・Claude Code の従量／企業プラン）
  • 変わらない人：定額（Pro / Max）。支払いは定額のまま、恩恵は「同じ枠でより多く動く」形
  • 効かせるコツ：前提（フォーマット・用語集・先週のレポート）を毎回同じ文面・同じ順で先頭に置く。日付・作業番号など毎回変わる値は前提から外す
🎁 この「前提を固定する型」を含む厳選10・対照シート・シミュレーターは、プレゼント図書館から受け取れます

「サイバー能力 Critical」と、巻き添えで止まる話

GPT-6 Astra は OpenAI の枠組みで初めて「Criticalクリティカル」に到達したモデル ✅ ただし普通に使う人への影響は限定的です。

  • 「実際に攻撃できる試作コード（PoCエクスプロイト）を作る」高度な依頼は、両モデルとも断る
  • 守る側の作業（コードの安全レビュー、脆弱性の修正）には使える
  • Fable 5.1 は「発見には使えるが、開発には使えない」と明記。Claude Code のサイバー系の余計な介入は 1セッションあたり約60%減
openai.com/index/gpt-6-astra/ — safety section

When safety checks trigger, ChatGPT and Codex may pause a task and ask for confirmation; via the API the request stops. We are working to reduce how often this happens.

日本語訳: 安全チェックが働くと、ChatGPT や Codex では作業が一時停止して確認を求められることがある。API ではその場で止まる。回数を減らすよう調整中。

＝ サイバーと関係ない普通の作業でも、安全チェックの巻き添えで止まることがある（Astra 側・公式明記）。Fable 5.1 側は逆に、この巻き添えを約60%減らした発表でした。

くすりの素の設計

分子設計の当たりの割合が12標的で約50%（ふつうは10〜15%）。

計算の高速化

生物学の7モデルを最大2.5倍に高速化（結果は同じ）。GPU費用を30〜60%削減。

＝「原因を調べる」「新しい案を出す」仕事も任せられ始めた兆し。ただし研究デモ段階で、人の検証が前提。
